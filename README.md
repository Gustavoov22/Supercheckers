# Supercheckers

A 10x10 checkerboard game in a single HTML file. No build step, no dependencies.

## Play

Open `index.html` in any browser, or deploy the repo as a static site (Cloudflare Pages, GitHub Pages, Firebase Hosting).

## Features

- Full 10x10 checkers rules with forced captures and multi capture chains
- Flying queens: promoted pieces move any distance diagonally and capture in every direction
- AI opponent with three difficulties (minimax with alpha beta pruning)
- Teaching mode with move hints and plain language explanations
- Undo, game reset, and a local leaderboard
- Responsive layout for phone and desktop

## Deploy

This repo is ready for Cloudflare Pages as is: connect the repo, no build command, output directory set to the repo root.
